# Project reference sheets A–D (1 Oct 2026): the 80 screenshots, in words

Mike's claude.ai Project held 80 phone screenshots of @ozavry_ reels (`IMG_4784`–`IMG_4920`).
On 1 Oct they were cropped to the video frame and laid out as four contact sheets of twenty,
numbered 1–80, each frame with its five dominant colours, a label and its band. The sheet
images were kept in the Project rather than added to this public repo. The frames are
third-party clips, for internal art direction only.

Six of Mike's twenty favourites (`batch4/`, `LOOK_REFERENCE.md`) are among them, starred on
sheet D: #74 = fav 17, #75 = fav 13, #76 = fav 15, #77 = fav 5, #78 = fav 6, #80 = fav 16.
When Mike names a frame by number ("like #27"), this is the list to read.

Labels, "shows" and "teaches" were written by four parallel agents looking at each frame.
"Teaches" uses the LOOK_REFERENCE rule vocabulary.
